# E-Commerce-Order-Cancellation-System
# 🛒 Smart Cart Undo System

A console-based C++ project that demonstrates the implementation of the **Stack (LIFO)** data structure in an E-Commerce Order Cancellation System.

---

## 📌 Overview

This project allows users to perform shopping cart operations such as:

- Add Product
- Update Quantity
- Apply Coupon
- Change Delivery Address
- Undo Last Action
- Peek Last Action
- View Action History
- Confirm Order

Every action is stored inside a Stack, making Undo operations efficient using the Last In First Out (LIFO) principle.

---

## 🚀 Features

- Stack-based Undo System
- Push, Pop & Peek Operations
- Action History
- Current Order Display
- Order Confirmation Lock
- Random Order ID
- Colored Console Output
- Interactive Menu Interface
